# 待办事项（Todo）

一个零依赖的静态待办事项小应用：纯 HTML + CSS + JavaScript，不需要安装依赖或构建步骤。

## 运行方式

任选一种：

1. 双击 `index.html`，用浏览器直接打开。
2. 或者在本目录启动一个静态服务器：

   ```powershell
   python -m http.server 8000
   ```

   然后访问 <http://localhost:8000/>。

## 功能

- 添加任务：输入内容后按回车或点击「添加」
- 勾选复选框标记完成 / 未完成
- 双击任务文字可就地编辑（回车保存，Esc 取消）
- 删除单条任务
- 按「全部 / 未完成 / 已完成」筛选
- 一键清除所有已完成任务
- 顶部实时显示任务统计
- 数据保存在浏览器 `localStorage`（键名 `todos.v1`），刷新不丢失
- 自动跟随系统深色模式，移动端自适应

## 目录结构

```
index.html   页面结构
styles.css   样式（含深色模式与响应式）
app.js       逻辑（数据、渲染、localStorage）
```

## 数据存储

任务保存在浏览器的本地存储中，不会上传到任何服务器。想清空数据，可以在浏览器控制台执行：

```js
localStorage.removeItem('todos.v1');
```
